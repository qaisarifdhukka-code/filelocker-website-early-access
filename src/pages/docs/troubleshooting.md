# Troubleshooting

## The application won't install
Make sure you are using a supported version of Windows and that you downloaded the application from an official FileLocker distribution channel.

If Windows displays a security warning, verify that the installer was downloaded from the official FileLocker website or Microsoft Store listing.

## The recipient cannot open the protected file
Make sure the recipient:
- Has the complete protected file.
- Is using a current supported browser.
- Has not modified or corrupted the protected file.
- Is entering the correct password.

## The password doesn't work
Check:
- Capitalization
- Spaces
- Special characters
- Whether the password was copied correctly

**If the correct password has been lost, FileLocker cannot reset it.**

## The protected file was damaged during transfer
Try transferring the original protected file again. Avoid modifying the protected file after FileLocker creates it.

## The recipient's browser is unsupported
Ask the recipient to try a current version of:
- Chrome
- Edge
- Firefox
- Safari

## Still need help?
Contact FileLocker support at: [support@filelocker.online](mailto:support@filelocker.online)

Include the version of FileLocker you're using and a description of the problem. **Do not send your encryption password or confidential files to support.**
