# Supported Browsers

Recipients unlock FileLocker protected files using a supported modern browser.

FileLocker is designed for browsers that support the required modern Web APIs, including the Web Crypto API.

## Common supported browsers
- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Apple Safari

Browser compatibility can vary by browser version and operating system. For the best experience, recipients should use a current version of their browser.

## Does the recipient need an internet connection?
The unlock process is designed to occur locally and does not require uploading the protected file to a FileLocker cloud service.

However, the exact offline experience can depend on how the protected file is opened and the recipient's browser environment.
