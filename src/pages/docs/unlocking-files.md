# Unlocking a File

Recipients do not need to install the FileLocker desktop application.

The protected file contains the information required for the recipient's browser to perform the unlock process.

## Step 1 — Receive the protected file
The recipient receives the locked file through the delivery method you selected.

## Step 2 — Open the file
Open the protected file using a supported modern browser. No FileLocker account is required for the recipient.

## Step 3 — Enter the password
Enter the password provided by the sender. If a password hint was included, it may be displayed on the unlock screen.

## Step 4 — Unlock the file
Select **Unlock & Download**. The browser performs the decryption locally.

## Step 5 — Save the original file
After successful decryption, the recipient can save the recovered file to their device. The original protected file remains available separately unless the recipient chooses to remove it.

## Does the recipient need FileLocker?
**No.**
The recipient does not need to install the FileLocker desktop application or create a FileLocker account to unlock a protected file.
