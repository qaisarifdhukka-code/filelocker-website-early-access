# Passwords & Recovery

FileLocker uses a password as part of the process used to protect and recover your files.

## Create your own password
You can create a password yourself. For sensitive documents, use a password that is:
- Long
- Unique
- Difficult to guess
- Not reused for another service

## Generate a password automatically
FileLocker can generate a strong random password for you. If you use the generated password, save it somewhere secure before delivering the protected file.

## Password hints
You can optionally add a password hint. The purpose of the hint is to help the recipient remember the password without storing the password itself inside the protected file. **Do not put the actual password in the hint.**

## Can FileLocker recover my password?
**No.**
FileLocker is designed without a password-reset mechanism for protected files. If the correct password is lost, FileLocker cannot provide a replacement password to decrypt the protected content.

## How should I send the password?
For sensitive files, avoid sending the protected file and its password through the same channel whenever practical. 

For example:
- **File:** Email
- **Password:** Phone call or separate message

This reduces the risk of both pieces being exposed through a single compromised communication channel.
