# FileLocker FAQ

### Does FileLocker upload my files?
The normal locking workflow does not require uploading the original files to a FileLocker cloud service. File processing is performed locally on your device.

### Can FileLocker see my password?
FileLocker is designed so that your protected-file password is not available to a FileLocker cloud service.

### Can FileLocker decrypt my files?
The protected file is designed to be unlocked using the correct password. FileLocker does not provide a server-side password recovery mechanism for protected files.

### Does my recipient need to install FileLocker?
No. Recipients can unlock protected files using a supported modern browser.

### Does my recipient need an account?
No. The recipient does not need to create a FileLocker account to unlock a protected file.

### Can I protect a folder?
Yes. FileLocker can protect individual files or folders.

### Can I use FileLocker with a USB drive?
Yes. You can choose a USB drive as the destination for the protected file.

### Can I send a protected file by email?
Yes. The resulting protected file can be attached to an email like another file. For sensitive workflows, consider communicating the password separately.

### What happens if I lose the password?
The protected file cannot be recovered through a FileLocker password-reset process. Store passwords securely before delivering protected files.

### Does FileLocker require the internet?
The locking workflow is designed around local processing and does not require uploading the original file to a FileLocker cloud service. Certain application functions, such as licensing or access-related services, may require connectivity depending on the distribution and license configuration.

### Which operating systems can run FileLocker?
The FileLocker desktop application currently supports Windows 10 and Windows 11. The recipient does not need the FileLocker desktop application; the unlock experience uses a supported browser.
