# Delivering Protected Files

Once FileLocker creates a protected file, you can deliver it using the method that fits your workflow.

## Email
Attach the protected file to your email. The recipient receives the protected file rather than the original unprotected document. 

*Recommended: communicate the password through a separate channel.*

## USB Drive
Copy the protected file to a USB drive and hand the drive to your recipient. If the USB drive is lost, the protected contents still require the correct password to be recovered.

## File Transfer Services
You can use an existing file-transfer service to deliver the protected file. In this workflow, the service receives the protected file, rather than the original unprotected document.

## Why protect the file before transferring it?
FileLocker is designed so that protection travels with the file. The file remains protected regardless of whether you deliver it through:

`USB &rarr; Email &rarr; File transfer &rarr; External storage`
