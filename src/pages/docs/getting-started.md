# Getting Started with FileLocker

FileLocker is a Windows application that protects sensitive files before you deliver them.

The basic workflow is:
**Select destination &rarr; Select file &rarr; Set password &rarr; Lock file &rarr; Deliver &rarr; Recipient unlocks**

## System Requirements

FileLocker currently supports:
- Windows 10
- Windows 11

The recipient does **not** need to install FileLocker to unlock a protected file.

## Install FileLocker

Download and install FileLocker using the official distribution method provided with your license.

After installation:
1. Open FileLocker.
2. Follow the activation instructions.
3. Once activated, you can begin protecting files.

## Protect your first file

To create your first protected file:
1. Select where you want the locked file to be saved.
2. Select a file or folder.
3. Configure the available privacy options.
4. Create a password or generate one automatically.
5. Select **Encrypt & Save**.
6. Wait for FileLocker to finish processing.
7. Deliver the resulting locked file to your recipient.

## Important: Keep the password safe

FileLocker is designed so that the encryption password is not recoverable by FileLocker.

If you lose the password, the protected file cannot be unlocked through a FileLocker password-reset process. Always store or communicate the password securely.
