# Locking Files with FileLocker

FileLocker protects files locally on your computer and creates a self-contained locked file that can be delivered to another person.

## Step 1 — Select a destination
Choose where FileLocker should save the resulting locked file. You can select:
- A local drive
- A USB drive
- A custom folder

The original file remains in its existing location unless you enable the available deletion option.

## Step 2 — Select a file or folder
You can protect:
- Individual files
- Entire folders

Select the file or folder you want to protect and continue.

## Step 3 — Configure privacy options
Depending on the available options, you can choose to:

**Hide the original filename**  
The protected file can use a different name instead of exposing the original document name.

**Delete the original after locking**  
FileLocker can automatically remove the original unprotected file after the locking process completes. Use this option carefully. Make sure the protected file was created successfully before relying on the deletion of the original.

## Step 4 — Set a password
Create your own password or use FileLocker's password generator. You can also add an optional password hint. The password is required to recover the original file.

## Step 5 — Encrypt and save
Select **Encrypt & Save**. FileLocker processes the selected content locally and creates the protected file. The locking workflow does not require uploading the original file to a FileLocker cloud service.

## Step 6 — Deliver the protected file
Once the process completes, deliver the resulting locked file to your recipient. You can use:
- Email
- USB drive
- File transfer service
- External storage
- Another delivery method appropriate for your workflow
